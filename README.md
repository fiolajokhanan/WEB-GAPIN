# WEB-GAPIN - Dashboard Monitoring & AI Analytics Trafo PLN

Sistem Informasi Dashboard Monitoring Telemetri IoT & Analytics AI Anomali Gardu Distribusi PLN UP3 Mojokerto.

## Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **UI & Styling**: React, Tailwind CSS, Lucide Icons
- **Language**: TypeScript

## Getting Started

Jalankan development server:

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
